# ADR-0006：対応 OS 版と CPU

- ステータス：Proposed
- 決定者：技術責任者
- 期限：G1 開始
- 追跡：#1

## 背景

実機での確認結果がない OS や CPU を「対応」と記載しないことを要件にしている。
検証できる実機の範囲が、そのまま対応範囲になる。

## 決定（案）

- 先行して検証するのは Apple silicon Mac と Windows 11 x64。
- 最低 OS 版は、UI の試作後に、使う API と実機の結果から決める。
- Intel Mac と Windows ARM64 は、ビルドできるかと実機検証を分けて判断する。初期の正式対応は未定。
- Linux 単体、SSH、コンテナは初期版の対象外。ただし取得部とコアは Linux でもビルド・テストできるようにする。

## 検討した代替案

- 最初から全 CPU を対応にする：実機検証の負担が大きく、未検証の「対応」表示につながる。

## 影響

CI では、OS に依存しない crate を macOS / Windows / Linux でビルド・テストする。CI が通ることを実機対応の根拠にはしない。

## 受入条件

対応表の各行に、検証した OS 版、CPU、CLI 版、検証日がある。
