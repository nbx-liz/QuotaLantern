# ADR-0008：名称、公開主体、配布費用

- ステータス：Proposed
- 決定者：プロダクト責任者
- 期限：公開前（最初のリリースの前）
- 追跡：#1

## 背景

製品名 QuotaLantern は確定しているが、商標などの利用可能性は調べていない。
macOS の一般公開には署名と公証、Windows ではコード署名が必要になり、費用と鍵の管理主体を決める必要がある。

出典（いずれも 2026-10-21 確認）：

- <https://developer.apple.com/documentation/xcode/distributing-your-app-for-beta-testing-and-releases>
- <https://v2.tauri.app/distribute/sign/windows/>

## 決定（案）

- 名称は QuotaLantern を使う。最初のリリースの前に商標を調べる。
- 署名の費用、鍵の管理者、配布主体は未決。
- 署名鍵はソースや一般の CI 成果物に置かない。
- 公開物には、版、対応 OS / CLI 版、ソースの commit、依存一覧、SBOM、ビルド手順、ハッシュ、既知の制限を添える。
- 初期版の更新確認は手動とし、外部の更新サーバーを新設しない。
- 自動のクラッシュ送信は実装しない。診断は、アプリ版、OS 版、固定のエラーコード、合成入力での再現手順で行う。

## 検討した代替案

- 署名なしで配布する：費用はかからないが、OS の警告が出て「気軽さ」を損なう。署名しても安全性や無警告での起動は保証されない。

## 影響

リリースの時期が、署名の準備に左右される。

## 受入条件

最初のリリースの前に、商標の調査結果、署名と鍵の管理方法、配布主体が記録されている。
