# ADR-0007：ライセンスと公開

- ステータス：Accepted（2026-10-22）
- 決定者：プロダクト責任者
- 追跡：#1

## 背景

無料・OSS での公開は当初からの基本案だったが、ライセンスと公開の時期は未承認だった。

## 決定

- QuotaLantern は OSS とし、**MIT OR Apache-2.0** のデュアルライセンスで提供する。
- ソースは GitHub の公開リポジトリ `nbx-liz/QuotaLantern` で開発する。
- 貢献は、別段の意思表示がない限り同じデュアルライセンスで提供されたものとして扱う。

## 検討した代替案

- MIT のみ：最も簡潔だが、特許条項がない。
- Apache-2.0 のみ：特許条項はあるが、GPLv2 のプロジェクトとの互換性がない。
- GPL-3.0：派生物にもソースの公開を求める。利用・組み込みの障壁が上がる。

Rust エコシステムで一般的なデュアルライセンスを選び、利用者がどちらかを選べるようにした。

## 影響

- 署名費用と配布主体は、この ADR では決めない（ADR-0008）。
- 依存するライブラリのライセンスが、両ライセンスと矛盾しないことを依存追加時に確認する。

## 記録

- 2026-10-22：プロダクト責任者が決定。リポジトリを公開で作成し、`LICENSE-MIT` と `LICENSE-APACHE` を配置した。
