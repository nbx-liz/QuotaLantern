# ADR-0005：導入設定の保存と解除

- ステータス：Proposed
- 決定者：プロダクト責任者
- 期限：G1 開始
- 追跡：#1

## 背景

Claude Code の Status line を使うには、Claude Code 側の設定に取得部のコマンドを登録する必要がある。
QuotaLantern 側の接続設定・表示設定も、保存すれば利用データ以外の永続化になる。

## 決定（案）

- MVP では、設定手順を提示することを基本とする。
- 既存の Status line を無断で上書きしない。設定全体を複製しない。既存のコマンドと自動で連結しない。
  共存が必要な場合は、利用者が管理する構成とする（未決論点 Q-02）。
- QuotaLantern の設定は、初期版ではメモリ内に置く。保存してよい項目は、この ADR で列挙して承認するまで追加しない。
- アンインストールは、配布物と許可済みの導入設定だけを対象にする。既存の AI ツールの履歴や認証情報を削除しない。
  利用者が後から編集した設定は、無条件に元へ戻さない。

## 検討した代替案

- 導入時に設定を自動で書き換える：手軽だが、既存の設定を壊す危険と、秘密を含む設定を読む必要が生じる。

## 影響

初回設定の手間が増える。目標は、CLI にログイン済みの利用者が説明を見て 5 分以内に接続・停止・解除まで完了できること。

## 受入条件

- 既存の Status line がある環境とない環境の両方で、導入と解除の手順が成立する。
- 解除後に、QuotaLantern 由来の設定が残らない。
